# Security

## Reporting

Report security issues through a private GitHub security advisory for this repository. Do not include character saves, world saves, WGS profile archives, account identifiers, or other personal data in a public issue.

## Save Safety

RSDW Save Converter modifies local Xbox Game Pass save containers. Test new releases with disposable destinations and retain the generated profile backup until the imported save has loaded and synchronized successfully.

The application performs no network requests. Xbox cloud synchronization is handled by the game and Xbox services after the converter exits.
